# Contributing

Issues and pull requests are welcome. This is an early-stage project
(0.x-alpha), so please:

- Open an issue before large PRs — the replication-safety logic deserves
  discussion before code.
- Include the Longhorn / CAPI / Kubernetes versions your scenario uses.
- Note if you are running it in production-like conditions; the validation
  matrix in the README is the standard to compare against.
